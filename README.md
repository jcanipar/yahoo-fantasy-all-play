# Yahoo Fantasy Basketball All-Play Analyzer

A personal, non-commercial fantasy basketball analytics project using the Yahoo Fantasy Sports API and Google Sheets.

The application will automatically retrieve weekly team statistics from a private Yahoo Fantasy Basketball league and calculate alternative standings based on how each team would have performed against every other team in the league.

Features planned:
- Automated weekly statistics synchronization
- All-play standings and rankings
- Category-by-category performance comparisons
- Season-long historical analysis

The project will use Google Apps Script to synchronize data into a Google Sheets spreadsheet shared privately with league members.

This project is not affiliated with Yahoo and will not be monetized.
